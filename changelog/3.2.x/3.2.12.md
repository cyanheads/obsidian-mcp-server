# 3.2.12 — 2026-08-02

## Fixed

- **`serializeFrontmatter` re-attaches the body verbatim** ([#96](https://github.com/cyanheads/obsidian-mcp-server/issues/96)) — it was slicing one leading newline off the body to compensate for its own template's trailing `\n`, silently eating the blank separator line on every `obsidian_manage_frontmatter` `delete` and `obsidian_manage_tags` `add`/`remove` at the frontmatter location. The template now supplies only the fence terminator; the body passes through untouched, including no separator, several blank lines, CRLF line endings, and an empty body.
- **`obsidian_search_notes` `format()` no longer clips match context to 240 characters** ([#97](https://github.com/cyanheads/obsidian-mcp-server/issues/97)) — the render-side `truncate()` call capped `content[]` regardless of the caller's `contextLength`, so `content[]` silently diverged from the unclipped `structuredContent` once a caller widened the window. `contextLength`'s description now states it also sizes the rendered text.
